# Acknowledgments

This project was built with the support and resources of the open-source community.

## Developer

The project initiator requested a business listing platform that mirrors services like Google Business, Bing Places, JustDial, IndiaMart, and Yelp — with an open-source, Win95-styled interface.

## Open Source Libraries & Frameworks

### Backend
- **FastAPI** — Modern, fast (high-performance) web framework for Python
- **Pydantic** — Data validation and settings management
- **SQLAlchemy** — SQL toolkit and ORM
- **Uvicorn** — ASGI web server
- **Geopy** — Geocoding library
- **Requests** — HTTP library
- **Celery** — Distributed task queue (planned)
- **Redis** — In-memory data store
- **Boto3** — AWS SDK for Python (for S3 uploads)

### Frontend
- **React** — JavaScript library for user interfaces
- **Vite** — Next-generation build tool
- **TypeScript** — Typed superset of JavaScript
- **Leaflet** — JavaScript library for interactive maps
- **React Leaflet** — React UI components for Leaflet
- **React Router** — Declarative routing for React
- **Vitest** — Testing framework
- **ESLint** — Linter
- **Prettier** — Code formatter

### Maps & Infrastructure
- **OpenStreetMap** — Free, editable map of the world
- **Nominatim** — Search and geocoding engine for OpenStreetMap
- **Caddy** — Open-source reverse proxy with automatic HTTPS

### Security
- **Snyk** — Dependency vulnerability scanning
- **GitGuardian** — Secret detection and credential monitoring

## Icons & Design

- Win95 window styling inspired by classic Microsoft Windows 95 UI
- CSS implementation done in-house without external UI libraries
